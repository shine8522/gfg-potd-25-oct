Sum of Beauty of All Substrings

Given a string s, find the sum of the beauty of all its substrings.
beauty = max frequency − min positive frequency (zero-frequency characters ignore hote hain).

1 · Pehle beauty ko haath se samjho

String aabc. Start aur end tile par click karo (pehla click = start, doosra = end).

2 · Derive karo, memorize nahi

Tip: code line par click karo explanation ke liye; ← → keys se step karo.

3 · Teeno approaches

ApproachMethodTimeAux space
1 Brute forceHar substring ka map scratch seO(n³)O(1) (≤26 keys)
2 Incremental mapStart fix, sirf naye char ki count updateO(n²)O(1)
3 Incremental arraySame, par freq[26] arrayO(n²)O(1)

Sabse bada improvement repeated counting hatane se aaya (O(n³) → O(n²)). Map ki jagah array ek further simplification hai jo fixed alphabet ki wajah se possible hua — asymptotic time O(n²) hi rehta hai.

4 · O(n³) vs O(n²) — illustration

Ye operation growth ka illustration hai, precise runtime benchmark nahi.

Approach 1: O(n²) substrings × O(n) recounting = O(n³)
Approach 2/3: O(n²) substrings × O(1) frequency processing = O(n²) (alphabet fixed 26 hai, isliye O(1)).
